# Optional brand font: Cadillac Gothic

The dashboard's headings and names use **Cadillac Gothic** when it's available, and fall back to
Bai Jamjuree (bundled) when it isn't. Cadillac Gothic isn't included because it isn't publicly licensed.

To use it, either:

- install the font on the PC whose browser shows the dashboard (the TV PC), or
- put licensed web font files here, named exactly:
  - `CadillacGothic-Regular.woff2`
  - `CadillacGothic-Bold.woff2`

  then rebuild the dashboard (`npm run build`).
