# The 9T7 Racing logo (factory only)

The "9t7" variant's setup guide and licence certificates show the 9T7 Racing logo from this folder.

**LOCAL step:** copy the real 9T7 Racing logo here as one of:

- `9t7-logo.svg` (preferred: sharp at any size), or
- `9t7-logo.png` (at least 600 px wide, transparent background).

Use the supplied 9T7 Racing artwork only. Don't draw or recreate the logo.

Until a file is here, the documents show the company name in plain type instead. The "unbranded" variant never
uses this folder. Nothing in this folder is ever put into a cafe's installer.
