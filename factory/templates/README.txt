WHAT'S IN THIS FOLDER

- ${installer}
  The installer. Run it on the hub PC: the one PC every rig sends its data to.
- ${guide}
  Your setup guide. Print it and follow it step by step.
- ${certificate}
  Your licence certificate, with your licence code. Keep it safe.
- ${video}
  A short video that shows the setup.
- README.txt
  This file.


HOW TO INSTALL

1. Read the setup guide first.
2. Copy the installer to the hub PC and double-click it. Choose "Hub PC".
3. Write down the setup code shown at the end of the install, then follow the
   setup page and the guide.

Your cafe's details, rigs and licence are already inside this installer.


YOUR LICENCE

Your licence covers ${rigs_text} and ${games}. It is yours forever: there is
nothing to renew.

The licence code is printed on the licence certificate, also as a QR code. The
installer puts it in for you, so you only need it if you are asked for it.

To add rigs, games or features later, contact ${supplier}. You get a new code:
on the owner page, find the Licence card, paste it into the "Enter new code"
box and press "Use this code". There is no reinstall.
