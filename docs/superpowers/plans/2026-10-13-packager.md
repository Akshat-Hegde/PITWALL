# Pitwall Packager Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cafe owner installs Pitwall from one `Pitwall Setup.exe`. The hub starts with Windows and needs no Python or npm. The owner sets the cafe up and brands it from a browser page, and the hub backs itself up every night.

**Architecture:**
- **Two homes.** The hub separates *app files*, which are read-only and replaced on update, from *cafe files*: config, data, branding and backups, which are never touched by updates.
  - Frozen (installed): app files live next to `Pitwall.exe`; cafe files in `%ProgramData%\Pitwall`.
  - From source: both default to the current folder, so development is unchanged.
- **Owner settings.** Settings an owner may change (name, colours, logo, tagline, PINs, hours) live in `<data_dir>/settings.json`, layered over `config/hub.toml`. They're edited from a `/setup` page and pushed live to the TV through a new additive `cafe` feed message.
- **Build and install.** PyInstaller builds a one-folder app. An Inno Setup script installs it with a boot-time scheduled task, firewall rules and shortcuts.

**Tech Stack:** Python 3.11 (python.org build for packaging), FastAPI, PyInstaller 6, Inno Setup 6, React/Vite dashboard (prebuilt `dist/`), SQLite online-backup API.

**Spec:** the approved packager scope in chat on 2026-10-13. Six parts: one-folder build, installer with autostart, firewall and shortcuts, first-run setup page with branding pack, nightly backup, updater. The **updater** is out of this plan; it gets its own plan once the update source is chosen. Commercial context: one codebase, with each cafe differing only in config and branding.

## Global Constraints

- Python 3.11 only (`requires-python = ">=3.11"`); build the exe from a **python.org** 3.11 install, never the Microsoft Store one.
- Everything works offline on the cafe LAN. Nothing in this plan calls the internet.
- Every optional feature stays switchable in `[features]`.
- Never show IP addresses or technical diagnostics on the TV pages. Staff, owner and setup pages may show them.
- Phone numbers only with consent (unchanged; don't add new personal fields).
- WebSocket schema v1 is frozen: additive changes only, documented in `docs/WS_SCHEMA.md`.
- No F1, F2 or F3 logos, official F1 fonts, "Formula 1" or "FIA" text, or team or sponsor marks in anything shipped. The installer and app are branded **Pitwall**; the Python package stays `simtelemetry`.
- One git commit per task, all tests passing (`.venv\Scripts\python -m pytest -q` from the repo root; dashboard `npx vitest run` in `dashboard/`). Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Ask the user before installing software on this PC (python.org Python, Inno Setup) and before running the built installer here (it registers a boot task and firewall rules).
- The user's own live hub may be running on port 8000. Tests and smoke runs use spare ports (e.g. `--http-port 8199 --port 20899`) and a temp data dir.

```python
# hub/simtelemetry/paths.py
"""Where Pitwall's files live.

App files (TV pages, HTML, bundled tracks) ship with the program and are replaced by updates.
Cafe files (config, laps.db, settings, branding, backups) belong to the cafe and are never touched by updates.

- From a source checkout: app files come from the repo, cafe files from the current folder (as before).
- Installed (PyInstaller, sys.frozen): app files next to Pitwall.exe, cafe files in %ProgramData%\\Pitwall.
- PITWALL_HOME overrides where cafe files live (tests, a second hub on one PC).
"""

from __future__ import annotations

import os
import sys
from pathlib import Path

REPO_ROOT = Path(__file__).resolve().parents[2]


def is_frozen() -> bool:
    return bool(getattr(sys, "frozen", False))


def app_dir() -> Path:
    """Read-only program files: the PyInstaller bundle, or the repo root from source."""
    if is_frozen():
        return Path(getattr(sys, "_MEIPASS", Path(sys.executable).parent))
    return REPO_ROOT


def dashboard_dir() -> Path:
    """The built TV dashboard (index.html + assets)."""
    return app_dir() / "dashboard" if is_frozen() else REPO_ROOT / "dashboard" / "dist"


def home() -> Path:
    """The cafe's folder: config/, data/ and backups/ live under it."""
    override = os.environ.get("PITWALL_HOME")
    if override:
        return Path(override)
    if is_frozen():
        return Path(os.environ.get("PROGRAMDATA", r"C:\ProgramData")) / "Pitwall"
    return Path.cwd()


def config_path() -> Path:
    return home() / "config" / "hub.toml"
```

```python
def load_config(path: Path | None = None) -> AppConfig:
    """Load the given file, else <home>/config/hub.toml if present, else defaults.

    A relative data_dir is taken relative to the home folder (see paths.py), so an installed hub keeps
    its data in %ProgramData%\\Pitwall\\data whatever folder it was started from.
    """
    if path is None:
        path = paths.config_path()
        if not path.exists():
            return _anchored(AppConfig())
    with path.open("rb") as f:
        try:
            data = tomllib.load(f)
        except tomllib.TOMLDecodeError as exc:
            raise ConfigError(f"Invalid config file {path}:\n  {_describe_syntax_error(path, exc)}") from None
    try:
        return _anchored(AppConfig.model_validate(data))
    except ValidationError as exc:
        problems = "\n".join(f"  {_describe(path, err)}" for err in exc.errors())
        raise ConfigError(f"Invalid config file {path}:\n{problems}") from None


def _anchored(config: AppConfig) -> AppConfig:
    if not config.data_dir.is_absolute():
        config.data_dir = paths.home() / config.data_dir
    return config

"""Settings the cafe owner changes from /setup, kept in <data_dir>/settings.json and layered over hub.toml.

hub.toml stays the place for technical settings (ports, recorder, map); these are the owner's own.
"""

from __future__ import annotations

import json
import logging
import os
import re
from pathlib import Path

from pydantic import BaseModel, Field, ValidationError, field_validator, model_validator

from ..config import AppConfig

log = logging.getLogger(__name__)
_HEX = re.compile(r"^#[0-9A-Fa-f]{6}$")
_PIN = re.compile(r"^(\d{4,8})?$")


class CafeSettings(BaseModel):
    name: str = Field(min_length=1, max_length=40)
    tagline: str = Field("", max_length=60)
    accent: str = "#E10600"
    logo: str | None = None
    owner_pin: str = Field(min_length=4, max_length=8)
    staff_pin: str = ""
    open_hour: int = Field(10, ge=0, le=23)
    close_hour: int = Field(22, ge=1, le=24)
    setup_done: bool = False

    @field_validator("accent")
    @classmethod
    def _hex(cls, value: str) -> str:
        if not _HEX.match(value):
            raise ValueError("accent must be a colour like #E10600")
        return value.upper()

    @field_validator("owner_pin", "staff_pin")
    @classmethod
    def _digits(cls, value: str) -> str:
        if not _PIN.match(value):
            raise ValueError("PINs are 4 to 8 digits")
        return value

    @model_validator(mode="after")
    def _hours(self) -> "CafeSettings":
        if self.close_hour <= self.open_hour:
            raise ValueError("closing hour must be after opening hour")
        return self


class SettingsStore:
    def __init__(self, data_dir: Path) -> None:
        self.path = data_dir / "settings.json"
        self.branding_dir = data_dir / "branding"

    def load(self) -> CafeSettings | None:
        try:
            return CafeSettings.model_validate_json(self.path.read_text(encoding="utf-8"))
        except FileNotFoundError:
            return None
        except (OSError, ValidationError, ValueError) as exc:
            log.warning("Ignoring unreadable %s (%s); using hub.toml values", self.path, exc)
            return None

    def save(self, settings: CafeSettings) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self.path.with_suffix(".tmp")
        tmp.write_text(json.dumps(settings.model_dump(), indent=2), encoding="utf-8")
        os.replace(tmp, self.path)             # atomic: a power cut never leaves half a file


def apply_settings(config: AppConfig, s: CafeSettings) -> None:
    config.cafe.name = s.name
    config.cafe.tagline = s.tagline
    config.cafe.logo = s.logo
    config.cafe.branding = {**config.cafe.branding, "--brand-accent": s.accent}
    config.owner.pin = s.owner_pin
    config.staff.pin = s.staff_pin
    config.owner.open_hour, config.owner.close_hour = s.open_hour, s.close_hour

# hub/simtelemetry/core/backup.py
"""Backups: laps.db copied with SQLite's online backup (safe while the hub writes), plus settings.json,
branding/ and hub.toml, zipped as pitwall-YYYYMMDD-HHMM.zip. Restore puts them back (hub stopped)."""

from __future__ import annotations

import datetime as dt
import json
import shutil
import sqlite3
import tempfile
import zipfile
from pathlib import Path
from typing import Any

from .. import __version__

PATTERN = "pitwall-*.zip"


def make_backup(data_dir: Path, config_path: Path | None, target_dir: Path, now: dt.datetime) -> Path:
    target_dir.mkdir(parents=True, exist_ok=True)
    out = target_dir / f"pitwall-{now:%Y%m%d-%H%M}.zip"
    with tempfile.TemporaryDirectory() as tmp:
        snap = Path(tmp) / "laps.db"
        db = data_dir / "laps.db"
        if db.exists():
            src = sqlite3.connect(db)
            dst = sqlite3.connect(snap)
            with dst:
                src.backup(dst)
            dst.close()
            src.close()
        partial = out.with_suffix(".part")
        with zipfile.ZipFile(partial, "w", zipfile.ZIP_DEFLATED) as z:
            if snap.exists():
                z.write(snap, "laps.db")
            for name in ("settings.json", "rigs.json", "tv.json"):
                if (data_dir / name).exists():
                    z.write(data_dir / name, name)
            branding = data_dir / "branding"
            if branding.is_dir():
                for f in sorted(branding.iterdir()):
                    z.write(f, f"branding/{f.name}")
            if config_path is not None and config_path.exists():
                z.write(config_path, "hub.toml")
            z.writestr("manifest.json", json.dumps({"version": __version__, "at": now.isoformat()}))
        partial.replace(out)
    return out


def prune(target_dir: Path, keep: int) -> list[Path]:
    files = sorted(target_dir.glob(PATTERN))
    old = files[:-keep] if keep > 0 else []
    for f in old:
        f.unlink()
    return old


def restore(zip_path: Path, data_dir: Path, config_path: Path | None) -> None:
    data_dir.mkdir(parents=True, exist_ok=True)
    with zipfile.ZipFile(zip_path) as z:
        for name in z.namelist():
            if name == "manifest.json":
                continue
            if name == "hub.toml":
                if config_path is not None:
                    config_path.parent.mkdir(parents=True, exist_ok=True)
                    config_path.write_bytes(z.read(name))
                continue
            dest = data_dir / name
            dest.parent.mkdir(parents=True, exist_ok=True)
            with z.open(name) as src, dest.open("wb") as out:
                shutil.copyfileobj(src, out)


def last_backup(target_dir: Path) -> dict[str, Any] | None:
    files = sorted(target_dir.glob(PATTERN)) if target_dir.is_dir() else []
    if not files:
        return None
    f = files[-1]
    return {"file": f.name, "at": round(f.stat().st_mtime * 1000), "bytes": f.stat().st_size}
```

- [ ] **Step 2: The scheduled task**

`packaging/pitwall-task.xml`: a Task Scheduler 1.2 definition with:
- a `BootTrigger` with a 30 s delay
- `Principal` `UserId` `S-1-5-18` (SYSTEM), `RunLevel` `HighestAvailable`
- `Settings`: `RestartOnFailure` every `PT1M`, `Count` 999; `ExecutionTimeLimit` `PT0S`; `DisallowStartIfOnBatteries` false; `MultipleInstancesPolicy` `IgnoreNew`
- `Actions`: `Exec` running `"%ProgramFiles%\Pitwall\Pitwall.exe" run`, with `WorkingDirectory` `%ProgramData%\Pitwall`

The installer writes the real paths into it with `{app}` constants, so keep the placeholders `__APP__` and `__DATA__` in the XML and replace them in `[Code]`.

- [ ] **Step 3: The installer script**

`packaging/pitwall.iss` must cover:
- `[Setup]`:
  - `AppName=Pitwall`, `AppVersion={#AppVersion}`, `DefaultDirName={autopf}\Pitwall`
  - `PrivilegesRequired=admin`, `OutputBaseFilename=Pitwall-Setup-{#AppVersion}`, `SetupIconFile=pitwall.ico`
  - `WizardStyle=modern`, `CloseApplications=yes`, `UninstallDisplayIcon={app}\Pitwall.exe`.
- `[Files]`: `..\dist\Pitwall\*` → `{app}` (recursesubdirs); `pitwall-task.xml` → `{tmp}`; `..\tools\windows\*` → `{app}\tools`.
- `[Dirs]`: `{commonappdata}\Pitwall` with `Permissions: users-modify` (the TV launcher and the owner can read backups).
- `[Run]`, in this order:
  1. stop the old task: `schtasks /End /TN "Pitwall Hub"` (ignore errors);
  2. `netsh advfirewall firewall delete rule name="Pitwall hub"`;
  3. add the firewall rules: `netsh advfirewall firewall add rule name="Pitwall hub" dir=in action=allow program="{app}\Pitwall.exe" enable=yes profile=private,domain`. Also add two port rules, `protocol=UDP localport=20777` and `protocol=TCP localport=8000`, in case the cafe set the network profile to Public; label them "Pitwall telemetry" and "Pitwall pages";
  4. `schtasks /Create /F /TN "Pitwall Hub" /XML "{tmp}\pitwall-task.xml"`;
  5. `schtasks /Run /TN "Pitwall Hub"`;
  6. postinstall, checked by default: open `http://localhost:8000/setup` (`Flags: shellexec postinstall`).
- `[Icons]`:
  - **Pitwall TV**: `{app}\tools\Start TV.cmd`, with a Startup copy when the task "Open the TV page when this PC signs in" is ticked;
  - **Pitwall Staff**, **Pitwall Owner** and **Pitwall Setup**: URL shortcuts to `http://localhost:8000/staff`, `/owner` and `/setup`;
  - **Uninstall Pitwall**.
- `[UninstallRun]`: `schtasks /End` and `/Delete /F /TN "Pitwall Hub"`; the netsh `delete rule` lines.
- No `[UninstallDelete]` for `{commonappdata}\Pitwall`: the cafe's data survives uninstall and reinstall. Say so on the final uninstall message.
- `[Code]`: `PrepareToInstall` writes the task XML with `__APP__` / `__DATA__` replaced (`StringChangeEx`). Also add a `CurStepChanged(ssPostInstall)` wait of up to 20 s for `http://localhost:8000/api/health` before opening `/setup`, using `WinHttp.WinHttpRequest.5.1` via `CreateOleObject`.
- The version comes from the build: `ISCC.exe /DAppVersion=0.2.0`. `build.ps1` reads it with `& Pitwall.exe --version`.

Extend `packaging/build.ps1` after the smoke test:

```powershell
$version = (& $exe --version).Split(" ")[1]
$iscc = "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe"
& $iscc "/DAppVersion=$version" "$root\packaging\pitwall.iss"
Write-Host "Installer: $root\dist\Pitwall-Setup-$version.exe"
```

Set `OutputDir=..\dist` in `[Setup]`.
