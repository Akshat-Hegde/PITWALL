# Pitwall Packager Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cafe owner installs Pitwall from one `Pitwall Setup.exe`. The hub starts with Windows and needs no Python or npm. The owner sets the cafe up and brands it from a browser page, and the hub backs itself up every night.

**Architecture:**
- **Two homes.** The hub separates *app files*, which are read-only and replaced on update, from *cafe files*: config, data, branding and backups, which are never touched by updates.
  - Frozen (installed): app files live next to `Pitwall.exe`; cafe files in `%ProgramData%\Pitwall`.
  - From source: both default to the current folder, so development is unchanged.
- **Owner settings.** Settings an owner may change (name, colours, logo, tagline, PINs, hours) live in `<data_dir>/settings.json`, layered over `config/hub.toml`. They're edited from a `/setup` page and pushed live to the TV through a new additive `cafe` feed message.
- **Build and install.** PyInstaller builds a one-folder app. An Inno Setup script installs it with a boot-time scheduled task, firewall rules and shortcuts.

**Tech Stack:** Python 3.11 (python.org build for packaging), FastAPI, PyInstaller 6, Inno Setup 6, React/Vite dashboard (prebuilt `dist/`), SQLite online-backup API.

**Spec:** the approved packager scope in chat on 2026-10-13. Six parts: one-folder build, installer with autostart, firewall and shortcuts, first-run setup page with branding pack, nightly backup, updater. The **updater** is out of this plan; it gets its own plan once the update source is chosen. Commercial context: one codebase, with each cafe differing only in config and branding.

## Global Constraints

- Python 3.11 only (`requires-python = ">=3.11"`); build the exe from a **python.org** 3.11 install, never the Microsoft Store one.
- Everything works offline on the cafe LAN. Nothing in this plan calls the internet.
- Every optional feature stays switchable in `[features]`.
- Never show IP addresses or technical diagnostics on the TV pages. Staff, owner and setup pages may show them.
- Phone numbers only with consent (unchanged; don't add new personal fields).
- WebSocket schema v1 is frozen: additive changes only, documented in `docs/WS_SCHEMA.md`.
- No F1, F2 or F3 logos, official F1 fonts, "Formula 1" or "FIA" text, or team or sponsor marks in anything shipped. The installer and app are branded **Pitwall**; the Python package stays `simtelemetry`.
- One git commit per task, all tests passing (`.venv\Scripts\python -m pytest -q` from the repo root; dashboard `npx vitest run` in `dashboard/`). Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **The product name is a placeholder.** "Pitwall" is defined once in `hub/simtelemetry/brand.py`, and everything packaging-facing derives from it:
  - the ProgramData folder
  - the exe name, installer name and installer title
  - the boot task name, shortcut names and the uninstall entry
  - the reserved mDNS host name.

  Renaming must be a one-line change there. Never type the literal name into `paths.py`, the PyInstaller spec, `build.ps1`, the installer script or the task XML.
- **First-run setup is claimed with a one-time setup code.** The installer generates it, shows it on its last page and writes it to its install log. The hub logs it at start while setup isn't done. Without the code nobody on the LAN can claim `/setup` first. After setup the code is deleted and the owner PIN guards `/setup`.
- **Licensing is out of scope** (separate plan; required before any paying cafe, not for the pilot).
- **Software installs and running the installer:**
  - python.org Python 3.11 on this PC at Task 2 is **approved**.
  - Inno Setup at Task 6: ask first.
  - The built installer is **never run on this PC**. The user runs it on a spare PC or a Windows VM, so Task 6 prepares those steps.
- The user's own live hub may be running on port 8000. Tests and smoke runs use spare ports (e.g. `--http-port 8199 --port 20899`) and a temp data dir.

```python
# hub/simtelemetry/brand.py
"""The product name and every name derived from it. "Pitwall" is a placeholder: renaming is this one line.

Used by paths (ProgramData folder), the CLI --version, the PyInstaller spec (exe name), packaging/build.ps1 and
the installer (installer file, title, boot task, shortcuts, uninstall entry), and the mDNS host name when
that is built. The Python package stays `simtelemetry`.
"""

from __future__ import annotations

import re

PRODUCT_NAME = "Pitwall"

SLUG = re.sub(r"[^a-z0-9]+", "-", PRODUCT_NAME.lower()).strip("-")
EXE_NAME = re.sub(r"[^A-Za-z0-9]+", "", PRODUCT_NAME)          # Pitwall.exe
TASK_NAME = f"{PRODUCT_NAME} Hub"                                # Windows boot task
MDNS_HOST = f"{SLUG}.local"                                      # reserved for the mDNS feature
HOME_ENV = f"{EXE_NAME.upper()}_HOME"                            # e.g. PITWALL_HOME


def as_dict() -> dict[str, str]:
    """For build scripts: `python -c "from simtelemetry import brand, json; print(json.dumps(brand.as_dict()))"`."""
    return {"PRODUCT_NAME": PRODUCT_NAME, "SLUG": SLUG, "EXE_NAME": EXE_NAME, "TASK_NAME": TASK_NAME,
            "MDNS_HOST": MDNS_HOST, "HOME_ENV": HOME_ENV}
```

Everywhere below, `PITWALL_HOME` means `brand.HOME_ENV`, and `Pitwall` in a path means `brand.PRODUCT_NAME`.

```python
# hub/simtelemetry/paths.py
"""Where the program's files live.

App files (TV pages, HTML, bundled tracks) ship with the program and are replaced by updates.
Cafe files (config, laps.db, settings, branding, backups) belong to the cafe and are never touched by updates.

- From a source checkout: app files come from the repo, cafe files from the current folder (as before).
- Installed (PyInstaller, sys.frozen): app files next to the exe, cafe files in %ProgramData%\\<brand.PRODUCT_NAME>.
- The brand.HOME_ENV environment variable overrides where cafe files live (tests, a second hub on one PC).
"""

from __future__ import annotations

import os
import sys
from pathlib import Path

from . import brand

REPO_ROOT = Path(__file__).resolve().parents[2]


def is_frozen() -> bool:
    return bool(getattr(sys, "frozen", False))


def app_dir() -> Path:
    """Read-only program files: the PyInstaller bundle, or the repo root from source."""
    if is_frozen():
        return Path(getattr(sys, "_MEIPASS", Path(sys.executable).parent))
    return REPO_ROOT


def dashboard_dir() -> Path:
    """The built TV dashboard (index.html + assets)."""
    return app_dir() / "dashboard" if is_frozen() else REPO_ROOT / "dashboard" / "dist"


def home() -> Path:
    """The cafe's folder: config/, data/ and backups/ live under it."""
    override = os.environ.get(brand.HOME_ENV)
    if override:
        return Path(override)
    if is_frozen():
        return Path(os.environ.get("PROGRAMDATA", r"C:\ProgramData")) / brand.PRODUCT_NAME
    return Path.cwd()


def config_path() -> Path:
    return home() / "config" / "hub.toml"
```

```python
def load_config(path: Path | None = None) -> AppConfig:
    """Load the given file, else <home>/config/hub.toml if present, else defaults.

    A relative data_dir is taken relative to the home folder (see paths.py), so an installed hub keeps
    its data in %ProgramData%\\Pitwall\\data whatever folder it was started from.
    """
    if path is None:
        path = paths.config_path()
        if not path.exists():
            return _anchored(AppConfig())
    with path.open("rb") as f:
        try:
            data = tomllib.load(f)
        except tomllib.TOMLDecodeError as exc:
            raise ConfigError(f"Invalid config file {path}:\n  {_describe_syntax_error(path, exc)}") from None
    try:
        return _anchored(AppConfig.model_validate(data))
    except ValidationError as exc:
        problems = "\n".join(f"  {_describe(path, err)}" for err in exc.errors())
        raise ConfigError(f"Invalid config file {path}:\n{problems}") from None


def _anchored(config: AppConfig) -> AppConfig:
    if not config.data_dir.is_absolute():
        config.data_dir = paths.home() / config.data_dir
    return config
```

### Task 3: Owner settings and the `/setup` page

The owner sets the cafe up in a browser: name, tagline, accent colour, logo, owner PIN, staff PIN and opening hours.

**Who can change it:**
- **Before setup is done:** `/setup` only accepts changes with the **one-time setup code**.
  - The installer generates it by running `<exe> setup-code --new`, shows it on its last page and writes it to its install log.
  - A hub started without one (e.g. from source) generates it on first start.
  - While setup isn't done, the hub logs it at every start.
- **After setup:** the code is deleted and `/setup` needs the owner PIN.
- **Brute force:** wrong codes are rate-limited (10 wrong, then a 60 s lockout).

The code file sits in the cafe's data folder (`setup-code.txt`). Anyone signed in on the hub PC itself can read it, which is fine: the threat is someone else on the LAN, not the person at the hub PC.

```python
# hub/simtelemetry/core/setup_code.py
"""One-time setup code. The installer makes it (`<exe> setup-code --new`) and shows it on its last page; first-run
/setup accepts changes only with it, so nobody else on the cafe network can claim the hub first.
Deleted once setup is done (after that the owner PIN guards /setup)."""

from __future__ import annotations

import hmac
import os
import secrets
import time
from collections.abc import Callable
from pathlib import Path

ALPHABET = "23456789ABCDEFGHJKLMNPQRSTUVWXYZ"     # no 0/O, 1/I/L: easy to read off a screen
MAX_TRIES = 10
LOCK_S = 60


class SetupLocked(Exception):
    def __init__(self, seconds_left: int) -> None:
        super().__init__(f"Too many wrong setup codes. Try again in {seconds_left} s.")
        self.seconds_left = seconds_left


def _norm(code: str) -> str:
    return "".join(ch for ch in code.upper() if ch.isalnum())


class SetupCode:
    def __init__(self, data_dir: Path, clock: Callable[[], float] = time.monotonic) -> None:
        self.path = data_dir / "setup-code.txt"
        self._clock = clock
        self._wrong = 0
        self._locked_until = 0.0

    def current(self) -> str | None:
        try:
            code = self.path.read_text(encoding="utf-8").strip()
        except OSError:
            return None
        return code or None

    def new(self) -> str:
        raw = "".join(secrets.choice(ALPHABET) for _ in range(8))
        code = f"{raw[:4]}-{raw[4:]}"
        self.path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self.path.with_suffix(".tmp")
        tmp.write_text(code + "\n", encoding="utf-8")
        os.replace(tmp, self.path)
        return code

    def ensure(self) -> str:
        return self.current() or self.new()

    def check(self, given: str | None) -> bool:
        now = self._clock()
        if now < self._locked_until:
            raise SetupLocked(int(self._locked_until - now) + 1)
        code = self.current()
        ok = bool(code and given) and hmac.compare_digest(_norm(given or ""), _norm(code or ""))
        if ok:
            self._wrong = 0
            return True
        self._wrong += 1
        if self._wrong >= MAX_TRIES:
            self._wrong = 0
            self._locked_until = now + LOCK_S
        return False

    def clear(self) -> None:
        self.path.unlink(missing_ok=True)
```

The 10th wrong try sets the lock, so the next `check` (even with the right code) raises `SetupLocked`, matching `test_lockout_after_too_many_wrong_codes`.

```python
# hub/simtelemetry/core/settings.py
"""Settings the cafe owner changes from /setup, kept in <data_dir>/settings.json and layered over hub.toml.

hub.toml stays the place for technical settings (ports, recorder, map); these are the owner's own.
"""

from __future__ import annotations

import json
import logging
import os
import re
from pathlib import Path

from pydantic import BaseModel, Field, ValidationError, field_validator, model_validator

from ..config import AppConfig

log = logging.getLogger(__name__)
_HEX = re.compile(r"^#[0-9A-Fa-f]{6}$")
_PIN = re.compile(r"^(\d{4,8})?$")


class CafeSettings(BaseModel):
    name: str = Field(min_length=1, max_length=40)
    tagline: str = Field("", max_length=60)
    accent: str = "#E10600"
    logo: str | None = None
    owner_pin: str = Field(min_length=4, max_length=8)
    staff_pin: str = ""
    open_hour: int = Field(10, ge=0, le=23)
    close_hour: int = Field(22, ge=1, le=24)
    setup_done: bool = False

    @field_validator("accent")
    @classmethod
    def _hex(cls, value: str) -> str:
        if not _HEX.match(value):
            raise ValueError("accent must be a colour like #E10600")
        return value.upper()

    @field_validator("owner_pin", "staff_pin")
    @classmethod
    def _digits(cls, value: str) -> str:
        if not _PIN.match(value):
            raise ValueError("PINs are 4 to 8 digits")
        return value

    @model_validator(mode="after")
    def _hours(self) -> "CafeSettings":
        if self.close_hour <= self.open_hour:
            raise ValueError("closing hour must be after opening hour")
        return self


class SettingsStore:
    def __init__(self, data_dir: Path) -> None:
        self.path = data_dir / "settings.json"
        self.branding_dir = data_dir / "branding"

    def load(self) -> CafeSettings | None:
        try:
            return CafeSettings.model_validate_json(self.path.read_text(encoding="utf-8"))
        except FileNotFoundError:
            return None
        except (OSError, ValidationError, ValueError) as exc:
            log.warning("Ignoring unreadable %s (%s); using hub.toml values", self.path, exc)
            return None

    def save(self, settings: CafeSettings) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self.path.with_suffix(".tmp")
        tmp.write_text(json.dumps(settings.model_dump(), indent=2), encoding="utf-8")
        os.replace(tmp, self.path)             # atomic: a power cut never leaves half a file


def apply_settings(config: AppConfig, s: CafeSettings) -> None:
    config.cafe.name = s.name
    config.cafe.tagline = s.tagline
    config.cafe.logo = s.logo
    config.cafe.branding = {**config.cafe.branding, "--brand-accent": s.accent}
    config.owner.pin = s.owner_pin
    config.staff.pin = s.staff_pin
    config.owner.open_hour, config.owner.close_hour = s.open_hour, s.close_hour
```

```python
# hub/simtelemetry/api/setup.py
"""/setup: first-run setup and branding. Before setup: the one-time setup code. After: the owner PIN."""

from __future__ import annotations

import hmac
from pathlib import Path
from typing import TYPE_CHECKING, Any

from fastapi import APIRouter, Header, HTTPException, UploadFile
from fastapi.responses import FileResponse
from pydantic import ValidationError

from ..core.feed import lan_address
from ..core.settings import CafeSettings, SettingsStore, apply_settings
from ..core.setup_code import SetupCode, SetupLocked
from .. import brand

if TYPE_CHECKING:
    from ..hub import Hub

SETUP_PAGE = Path(__file__).with_name("setup.html")
LOGO_TYPES = {"image/png": ".png", "image/jpeg": ".jpg", "image/webp": ".webp"}
MAX_LOGO_BYTES = 1024 * 1024


def setup_router(hub: Hub) -> APIRouter:
    router = APIRouter()
    store = SettingsStore(hub.config.data_dir)
    setup_code = SetupCode(hub.config.data_dir)

    def current() -> CafeSettings | None:
        return store.load()

    def guard(pin: str | None, code: str | None) -> None:
        """Before setup: the one-time setup code. After: the owner PIN."""
        s = current()
        if s is not None and s.setup_done:
            if not pin or not hmac.compare_digest(pin, s.owner_pin):
                raise HTTPException(401, "Enter the owner PIN to change the setup.")
            return
        try:
            ok = setup_code.check(code)
        except SetupLocked as exc:
            raise HTTPException(429, str(exc)) from None
        if not ok:
            raise HTTPException(401, "Enter the setup code from the installer's last page "
                                     "(also in the hub's log, or run: <exe> setup-code).")

    @router.get("/setup")
    def page() -> FileResponse:
        return FileResponse(SETUP_PAGE)

    @router.get("/api/setup")
    def state() -> dict[str, Any]:
        s = current()
        c = hub.config
        return {
            "product": brand.PRODUCT_NAME,
            "setup_done": bool(s and s.setup_done),
            "needs_code": not (s and s.setup_done),
            "name": c.cafe.name, "tagline": c.cafe.tagline, "logo": c.cafe.logo,
            "accent": c.cafe.branding.get("--brand-accent", "#E10600"),
            "open_hour": c.owner.open_hour, "close_hour": c.owner.close_hour,
            "hub_address": lan_address(), "http_port": c.network.http_port, "udp_port": c.network.udp_port,
            "rigs": [{"rig_id": r.ip, "name": r.name} for r in hub.registry.all()],
        }

    @router.post("/api/setup")
    def save(body: dict[str, Any], x_owner_pin: str | None = Header(None),
             x_setup_code: str | None = Header(None)) -> dict[str, Any]:
        guard(x_owner_pin, x_setup_code)
        old = current()
        try:
            s = CafeSettings(**{**body, "logo": old.logo if old else hub.config.cafe.logo, "setup_done": True})
        except ValidationError as exc:
            raise HTTPException(400, "; ".join(f"{'.'.join(map(str, e['loc']))}: {e['msg']}" for e in exc.errors()))
        store.save(s)
        apply_settings(hub.config, s)
        setup_code.clear()                      # used up: from now on the owner PIN guards /setup
        return state()

    @router.post("/api/setup/logo")
    async def logo(file: UploadFile, x_owner_pin: str | None = Header(None),
                   x_setup_code: str | None = Header(None)) -> dict[str, Any]:
        guard(x_owner_pin, x_setup_code)
        ext = LOGO_TYPES.get(file.content_type or "")
        data = await file.read()
        if ext is None:
            raise HTTPException(400, "Use a PNG, JPEG or WebP image.")
        if len(data) > MAX_LOGO_BYTES:
            raise HTTPException(400, "The logo must be under 1 MB.")
        store.branding_dir.mkdir(parents=True, exist_ok=True)
        for old in store.branding_dir.glob("logo.*"):
            old.unlink()
        (store.branding_dir / f"logo{ext}").write_bytes(data)
        hub.config.cafe.logo = f"logo{ext}"
        s = current()
        if s is not None:
            store.save(s.model_copy(update={"logo": hub.config.cafe.logo}))
        return {"logo": hub.config.cafe.logo}

    @router.get("/api/cafe/logo")
    def serve_logo() -> FileResponse:
        name = hub.config.cafe.logo
        path = store.branding_dir / name if name else None
        if path is None or not path.is_file():
            raise HTTPException(404, "No logo")
        return FileResponse(path, headers={"Cache-Control": "no-cache"})

    return router
```

```python
# hub/simtelemetry/core/backup.py
"""Backups: laps.db copied with SQLite's online backup (safe while the hub writes), plus settings.json,
branding/ and hub.toml, zipped as pitwall-YYYYMMDD-HHMM.zip. Restore puts them back (hub stopped)."""

from __future__ import annotations

import datetime as dt
import json
import shutil
import sqlite3
import tempfile
import zipfile
from pathlib import Path
from typing import Any

from .. import __version__, brand

PATTERN = f"{brand.SLUG}-*.zip"            # pitwall-20261013-0400.zip with the current name


def make_backup(data_dir: Path, config_path: Path | None, target_dir: Path, now: dt.datetime) -> Path:
    target_dir.mkdir(parents=True, exist_ok=True)
    out = target_dir / f"{brand.SLUG}-{now:%Y%m%d-%H%M}.zip"
    with tempfile.TemporaryDirectory() as tmp:
        snap = Path(tmp) / "laps.db"
        db = data_dir / "laps.db"
        if db.exists():
            src = sqlite3.connect(db)
            dst = sqlite3.connect(snap)
            with dst:
                src.backup(dst)
            dst.close()
            src.close()
        partial = out.with_suffix(".part")
        with zipfile.ZipFile(partial, "w", zipfile.ZIP_DEFLATED) as z:
            if snap.exists():
                z.write(snap, "laps.db")
            for name in ("settings.json", "rigs.json", "tv.json"):
                if (data_dir / name).exists():
                    z.write(data_dir / name, name)
            branding = data_dir / "branding"
            if branding.is_dir():
                for f in sorted(branding.iterdir()):
                    z.write(f, f"branding/{f.name}")
            if config_path is not None and config_path.exists():
                z.write(config_path, "hub.toml")
            z.writestr("manifest.json", json.dumps({"version": __version__, "at": now.isoformat()}))
        partial.replace(out)
    return out


def prune(target_dir: Path, keep: int) -> list[Path]:
    files = sorted(target_dir.glob(PATTERN))
    old = files[:-keep] if keep > 0 else []
    for f in old:
        f.unlink()
    return old


def restore(zip_path: Path, data_dir: Path, config_path: Path | None) -> None:
    data_dir.mkdir(parents=True, exist_ok=True)
    with zipfile.ZipFile(zip_path) as z:
        for name in z.namelist():
            if name == "manifest.json":
                continue
            if name == "hub.toml":
                if config_path is not None:
                    config_path.parent.mkdir(parents=True, exist_ok=True)
                    config_path.write_bytes(z.read(name))
                continue
            dest = data_dir / name
            dest.parent.mkdir(parents=True, exist_ok=True)
            with z.open(name) as src, dest.open("wb") as out:
                shutil.copyfileobj(src, out)


def last_backup(target_dir: Path) -> dict[str, Any] | None:
    files = sorted(target_dir.glob(PATTERN)) if target_dir.is_dir() else []
    if not files:
        return None
    f = files[-1]
    return {"file": f.name, "at": round(f.stat().st_mtime * 1000), "bytes": f.stat().st_size}
```

- **Updater** (own plan, once the update source is decided: GitHub Releases or your own URL):
  - a release manifest
  - an "Update available" card on the owner page
  - a backup before the update (Task 5's `make_backup`)
  - a silent `<exe>-Setup-x.y.z.exe /VERYSILENT` run as the update mechanism (the installer already keeps cafe files)
  - rollback by reinstalling the previous version.
- **mDNS** (small, own task): advertise `brand.MDNS_HOST` (e.g. `pitwall.local`) so phones and the TV can use a name instead of an IP. Rigs still need the IP, because F1 25 takes an address.
- **Multi-game** (own plan): run several game adapters side by side, then the ACC adapter, then AC. The user owns both games for recording test data.
- **Before selling:** a 4×2 / 4×3 MULTIVIEW grid for 7+ rigs, and a profanity filter for driver names.
